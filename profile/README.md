## 🫥 VANISH CORE (CONCEPT) — `ACTIVATE → DISAPPEAR → REPOSITION`

No public ROB RUN cheat currently lists a "Vanish" module, but the concept is straightforward: make your character invisible to other players, or hide your model locally while keeping your position server-side. In practice, two approaches exist in similar games.

- **Client-Side Model Hiding** — your character model is not rendered on your own screen, but other players still see you. This is cosmetic and does not hide you from enemies.
- **Server-Side Invisibility** — your character is flagged as hidden to other clients. This requires server-side changes and is the only form that would actually make you vanish from other players.
- **Ghost Mode / Noclip** — pass through walls and obstacles without being seen. This is a movement cheat, not true invisibility, but it achieves a similar "disappear from sight" effect.
- **Smoke & Concealment Tools** — in-game smoke grenades and hiding spots already provide legitimate concealment. A vanish cheat would bypass these mechanics.

**⚠️ Reality Check:** Kefir's server checks specifically rule out "moving faster than allowed, walking through walls, flying or teleporting" and "making yourself immortal."
